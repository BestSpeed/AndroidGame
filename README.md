# بازی‌خونه | BAZIKHUNEH 🎮

> **EASY TO LEARN — HARD TO MASTER — FUN TO REPLAY**

«بازی‌خونه» یک بازی **Multiplayer Party / Casual Competitive** برای اندروید است:
مجموعه‌ای از مینی‌گیم‌های سریع، ساده و نوستالژیک. وارد شو، در کمتر از یک دقیقه مسابقه بده،
و از صفحه نتیجه فقط با ۲ تپ دوباره بازی کن.

**وضعیت:** نسخه MVP (سه مینی‌گیم، مولتی‌پلیر واقعی، ربات، اقتصاد، اتاق خصوصی، لیدربرد) — قابل اجرا و تست.

---

## اجرای سریع (Local Dev)

```bash
npm install
npm start            # سرور + کلاینت روی http://localhost:8080
npm test             # تست‌های واحد (node:test)
node scripts/smoke.js   # تست سرتاسری (End-to-End): لاگین → صف → مچ ۸ نفره → ۳ راند → پاداش
npm run build:configs   # بازتولید کانفیگ نهفته کلاینت (بعد از تغییر هر فایل در configs/)
```

## حالت آفلاین 📴

بازی دو مسیره است:
- **آنلاین:** سرور در دسترس باشد → مولتی‌پلیر واقعی، اتاق خصوصی، لیدربرد سراسری (همه چیز سرور-معتبر).
- **آفلاین:** سرور در دسترس نباشد (یا «حالت آفلاین» در تنظیمات فعال شود) → موتور محلی با **همان قوانین و کانفیگ‌ها**
  مچ ۸ نفره با ربات‌ها، چالش روز، اقتصاد، پاداش‌ها و ریمچ را اجرا می‌کند؛ پیشرفت در دستگاه ذخیره می‌شود.
  قابلیت‌های نیازمند شبکه (اتاق خصوصی، خرید واقعی، دوستان) صادقانه «نیازمند اتصال» گزارش می‌شوند.

منطق آفلاین در `client/js/offline/` قرار دارد و پورت مستقیم ماژول‌های `server/src/games/*` است؛
کانفیگ مشترک از `configs/` با `npm run build:configs` در `client/js/configs.generated.js` نهفته می‌شود.

متغیرهای محیطی:

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `8080` | پورت سرور |
| `SERVER_ENV` | `development` | `development` / `staging` / `production` |
| `DATA_DIR` | `./data` | مسیر دیتابیس فایل‌ها |
| `API_BASE_URL` | `(same origin)` | فقط برای دیپلوی جدا بودن کلاینت |
| `ANALYTICS_KEY` | — | کلید سرویس آنالیتیکس (فعلاً استاب؛ سمت سرور می‌ماند) |
| `IAP_ENV` | `mock` | `mock` / `production` |

هیچ Secretای در کلاینت قرار نمی‌گیرد (بند ۴۸ سند محصول).

## تصمیم فنی اصلی (مهم)

محیط ساخت فعلی به **Unity/Android SDK** دسترسی ندارد؛ برای تحویل یک محصول *واقعی و قابل اجرا*
(نه پروتوتایپ نمایشی)، معماری به این شکل انتخاب شده است:

- **Client:** HTML5 (Canvas + ES Modules)، موبایل-فرست و Portrait، کاملاً فارسی/RTL — همان تکنولوژی‌ای
  که داخل WebView اندروید اجرا می‌شود.
- **Server:** گیم‌سرور **Server-Authoritative** با Node.js + WebSocket (منطق مسابقه، ضدتقلب، پاداش‌ها).
- **بسته‌بندی اندروید:** از طریق **Capacitor** (WebView skin) — ساختار آماده است، ساخت APK نیازمند
  Android SDK است و مراحل آن در `DEPLOYMENT.md` آمده (بند واضح در `TODO.md`).

این انتخاب هر دو مسیر آینده را باز نگه می‌دارد: (۱) انتشار همین بیلد با Capacitor،
(۲) پورت منطق بازی به Unity با استفاده از همین پروتکل شبکه و کانفیگ‌ها (به `ARCHITECTURE.md` مراجعه شود).

## مینی‌گیم‌های MVP

| نام فارسی | نام داخلی | ژانر |
|---|---|---|
| دست‌به‌کار | `ReactionGame` | واکنش + حافظه + فریب |
| مار محله | `SnakeArena` | مار کلاسیک چندنفره — آخرین بازمانده |
| مسابقه کوچه | `StreetRace` | ریس آرکید از بالا، ۳ پیست |

## ساختار مخزن

```
client/        کلاینت بازی (وب/WebView) — ماژول‌های مجزا برای هر سیستم
server/        گیم‌سرور و API — منطق معتبر مسابقه، اقتصاد، ضدتقلب
configs/       تنظیمات Data-Driven (اقتصاد، ربات‌ها، مچ‌میکینگ، فروشگاه…)
tests/         تست‌های واحد        scripts/  تست E2E و ابزارها
android/       تنظیمات و راهنمای ساخت با Capacitor
*.md           مستندات (معماری، طراحی بازی، شبکه، بک‌اند، اقتصاد، …)
```
